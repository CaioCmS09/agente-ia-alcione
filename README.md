# 🤖 Agente IA - Alcione Santos Calçados

Agente inteligente via WhatsApp para atendimento e automação comercial da empresa **Alicione Santos Calçados**, desenvolvido com **n8n** + **OpenAI**.

---

## 🧠 Funcionalidades

- Recebe e interpreta mensagens de texto dos clientes
- Detecta intenção do cliente e responde automaticamente
- Usa **memória simples** e **memória longa** (Redis) para conversas contextuais
- Suporte a **áudio (voz)**: converte áudios para texto com Whisper
- Detecta tipos de conteúdo: PDF, imagem ou vídeo, e responde de forma específica
- Para de responder automaticamente quando um atendente humano entra na conversa
- Consulta planilhas de preços e promoções via Google Sheets
- Processa informações usando funções internas do n8n e GPT

---

## 🔗 Tecnologias e integrações

- [n8n](https://n8n.io)
- [OpenAI GPT-4](https://platform.openai.com)
- [Redis](https://redis.io) (memória longa)
- [Supabase](https://supabase.com) (futuras implementações)
- Google Sheets
- WhatsApp (via Chatwoot)
